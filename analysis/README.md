# Analysis (not started)

Notebooks, statistical tests and plots. Paired comparisons (S1 vs S4, S2 vs S3)
run on identical test documents, so McNemar's test applies rather than an
unpaired comparison of aggregate rates.

Interval estimates should be clustered at the **person** level, not the image
level: the three quality tiers of one document and the six documents of one
record share an identity, so treating images as independent understates the
intervals by roughly a factor of 1.7.
